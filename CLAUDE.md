# JobBoardsReview (JBR)

Review and pricing-intelligence site for US job boards, with a healthcare focus.
Side venture. Sagar builds it; Palak is the public-facing founder.

Live site is still the old Lovable SPA. **This repo is the replacement and is not
yet deployed.** Getting it live is the current priority.

## Stack

- Next.js 16 (App Router, Turbopack), React 18, Tailwind
- Supabase: submissions, reviews, newsletter
- Board and blog content: **flat files in `data/`**, not the database
- Deploy target: Vercel

## Commands

```bash
npm run dev      # development, http://localhost:3000
npm run build    # production build — must exit 0 before any commit
npm start        # serve the production build
```

Windows: use Git Bash, not PowerShell. PowerShell aliases `curl` to
`Invoke-WebRequest` and has no `grep`; `&&` fails on PowerShell 5.1.

## Where things live

| Path | Holds |
| --- | --- |
| `data/jobboards/*.js` | one file per board, ~85 boards |
| `data/index.js` | imports and indexes every board; regenerated by admin |
| `data/boardProsCons.js`, `boardDecisionTags.js`, `boardHighlightGroups.js`, `boardMetrics.js` | per-board metadata keyed by slug |
| `data/blogs.js` | blog posts |
| `data/siteContent.js` | homepage and legal page copy |
| `app/admin/actions.js` | admin server actions — writes data files to disk |
| `.agy/skills/` | agent scripts (pricing auditor, board scraper) |

Adding or removing a board means touching the board file **and all five**
metadata/index files. Build failures after a removal are almost always a
leftover reference in one of them.

## Hard rules

1. **Never commit or push unless Sagar asks.** Run the build, show the diff, stop.
2. **Never invent facts.** Board prices, dates, descriptions, reviews. If a fact
   isn't in the repo or from a source you checked, say so and stop.
3. **Change only what the task names.** But do NOT revert unrelated uncommitted
   changes you find — they are probably deliberate. Flag them instead.
4. `npm run build` must exit 0 before anything is considered done.
5. Agents never publish. They gather and draft; Sagar presses publish.

## Known gotchas — all of these have bitten already

- **`cookies()` and `headers()` are async in Next 15+.** Must be awaited. Missing
  `await` on `cookies()` throws; missing it on `headers()` fails silently inside
  a try/catch and makes rate limiting treat every visitor as `127.0.0.1`.
- **Admin is local-only by design.** `app/admin/actions.js` writes data files with
  `fs.writeFileSync`. Serverless filesystems are read-only, so `/admin` is
  env-gated to return 404 in production. Approving a board = run `npm run dev`,
  approve, commit, push, Vercel rebuilds. This is intentional, not a bug.
- **Submissions live in Supabase, board data lives in files.** Both are involved
  in approval. In `approveSubmissionAction` the Supabase status update must stay
  the **last** operation, after the file writes succeed — otherwise a failed write
  leaves a submission marked approved with no board page.
- **Supabase free tier pauses after about a week of inactivity.** Symptom: an
  empty `{}` error object from any query. Everything DB-backed dies at once.
- **`package.json` has held hallucinated versions.** `react-quill` was pinned to a
  non-existent `^0.0.2`. Check that a version actually exists before trusting it.
- **Board data was generated, not verified.** Several boards are dead or have moved
  (Stack Overflow Jobs closed 2022, Chronicle Vitae retired). A failed DNS lookup
  means the URL is wrong — it does **not** prove the board is dead. Verify before
  deleting anything.
- `puppeteer` and `cheerio` are devDependencies only. They are used by the agent
  scripts, never by the site. Keep them out of `dependencies` or Vercel downloads
  Chromium on every build.

## Strategy, in one paragraph

Stop being a directory of everything; become the price-and-performance record for
US healthcare job boards. The asset is tracked pricing history plus verified
recruiter reviews — things an AI cannot generate. Discovery comes from being cited
by AI answers, not from ranking. Boards and vendors pay, not advertisers. The
buying window for 2027 recruiting budgets is November–December 2026, so shipping
now matters more than shipping polished.

Do not mass-produce AI-written pages. Scaled low-value content is what gets review
sites de-indexed, and it would destroy the only thing here worth having.
